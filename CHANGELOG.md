# Changelog

## [1.0.0] - 2026-10-25

First public release.

### Features
- Pin any window always-on-top in a screen corner with global hotkeys (Ctrl+Alt+P, or Ctrl+Alt+G for the window under the mouse).
- Cycle size, corner and transparency, and hide/restore the pinned window, all while the game keeps focus.
- One-key Netflix (Ctrl+Alt+N) and Prime Video (Ctrl+Alt+A) windows that open without browser bars and pin themselves automatically.
- Auto-hiding title bar: hidden while you play, shown when the mouse is over the window, hidden again 5 seconds after it leaves.
- System tray icon with a menu and a hotkey reference.
- Single-instance guard, so launching it twice doesn't cause hotkey conflicts.
- Restores every window it changed when you unpin or quit.
